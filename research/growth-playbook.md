# Growth playbook (owned by Reach)

Each action names the agent that owns it. Evidence: [ListingView, Etsy algorithm 2026](https://listingview.io/blogs/how-etsy-s-algorithm-actually-works-in-2026), [Marmalead, algorithm 2026](https://blog.marmalead.com/etsy-algorithm-2026/), [Growing Your Craft, SEO guide 2026](https://www.growingyourcraft.com/blog/etsy-search-seo-ranking-getting-found), [Etsy SEO for new shops 2026](https://getbetterlisting.com/en/blog/2026-etsy-seo-for-new-shops), [Listify, more views 2026](https://www.listifyai.net/blog/how-to-get-more-views-etsy-2026). These are third-party blogs, not Etsy itself; the sources disagree on how much each factor weighs.
