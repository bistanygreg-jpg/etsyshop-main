# What we changed vs. what moved (Hawk owns this; started Nov 19, 2026)

**Owner question (Nov 19):** can we tell which changes drove more visitors? Yes, roughly, if we log every change with its date and take the same stats snapshot every week. That's what this file does.

## How it works

1. **Every agent logs a change here the day it goes live.** One row: date, what changed, which listings, which traffic source it should move.
2. **Every Monday, Hawk adds one snapshot row.** The owner pastes or screenshots the same 4 Etsy screens (about 2 minutes). We can't read Etsy ourselves, because it blocks automated access.
   - Shop Manager → Stats, **last 7 days**: visits, views, orders, revenue
   - Traffic sources (Etsy search, Etsy app, Etsy ads, social media by platform, direct, other)
   - Listings tab, sorted by visits (the top 10)
   - Etsy Ads: views, clicks, spend, orders
3. **Hawk compares each week with the week before.** For each change, check the source it was meant to move:
   - Social posts → "Social media" visits (Instagram, Facebook, Pinterest, TikTok shown separately)
   - Titles, tags, first photos → Etsy search visits and views on those listings
   - Ads → ad clicks, and spend per click
   - Cyber Specials → Etsy search, Etsy app and sale-listing visits
   - Sharing with friends and family → direct visits

## Limits

- **Small numbers.** We have about 34 visits in 30 days, so a change of 5 visits can be luck. Call something a winner only when it repeats for 2 weeks, or moves a source by about 2x.
- **Changes overlap.** Cyber Specials, the new bundle and daily posting all land the same week, so we can name the likely driver, not prove it. Where we can, change one thing per listing per week.
- **Social shows up by platform, not by post.** Etsy shows "Instagram", not which post. Meta Business Suite, TikTok Studio and Pinterest show link clicks per post, and the Mac Shout job can read those.
